# Anti-amnesia tarihsel arşivi

Bu klasör, 40/40 prompt uygulaması kapanışından sonra ilk okuma bağlamından
çıkarılan tarihsel kayıtları tutar. Yeni ajanlar burayı varsayılan olarak
okumaz.

- `prompt-handoffs/` — Prompt 01–40 ve eski post-close handoff kayıtları
- `completed-context/` — tamamlanmış prompt dönemi `AGENT-CONTEXT`,
  `CODEX-STARTER` ve `TOKEN-BUDGET` belgeleri

Güncel durum için üst dizindeki
[`../CURRENT-STATE.md`](../CURRENT-STATE.md) ve
[`../LEDGER.md`](../LEDGER.md) yeterlidir.
