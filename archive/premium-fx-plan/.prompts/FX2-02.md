## 3. ADIMLAR

### Adım 1 — Token'ları mevcut `:root`'a ekle
`--ease-premium:` satırının **hemen altına**. **Yeni `:root` bloğu açma.**

```css
    /* ── FX2-02: hareket skalası ───────────────────────────── */
    --dur-1: 120ms;   /* basma durumu, mikro geri bildirim */
    --dur-2: 200ms;   /* buton/ikon durum değişimi */
    --dur-3: 320ms;   /* kart girişi, sekme geçişi */
    --dur-4: 480ms;   /* overlay / sheet */
    --dur-5: 800ms;   /* zemin / tema crossfade */

    --ease-out:    cubic-bezier(.16, 1, .3, 1);
    --ease-in:     cubic-bezier(.7, 0, .84, 0);
    --ease-spring: cubic-bezier(.34, 1.56, .64, 1);
    --ease-glide:  cubic-bezier(.65, 0, .35, 1);

    /* ── FX2-02: yükseklik skalası (katmanlı gölge + iç ışık) ── */
    --elev-0: none;
    --elev-1: 0 1px 2px rgba(0,0,0,.04), 0 2px 8px rgba(0,0,0,.04),
              inset 0 1px 0 rgba(255,255,255,.30);
    --elev-2: 0 2px 4px rgba(0,0,0,.05), 0 8px 20px rgba(0,0,0,.06),
              inset 0 1px 0 rgba(255,255,255,.34);
    --elev-3: 0 4px 8px rgba(0,0,0,.06), 0 16px 36px rgba(0,0,0,.09),
              inset 0 1px 0 rgba(255,255,255,.38);
    --elev-4: 0 8px 16px rgba(0,0,0,.08), 0 28px 60px rgba(0,0,0,.13),
              inset 0 1px 0 rgba(255,255,255,.42);

    /* ── FX2-02: basma ─────────────────────────────────────── */
    --press-scale: .965;
    --press-dim:   .92;
```

### Adım 2 — `--ease-premium` geriye uyumu (ZORUNLU)
Mevcut `--ease-premium:cubic-bezier(.16,1,.3,1);` satırını **şununla değiştir**:
```css
    --ease-premium: var(--ease-out);
```
> Bu satır **silinemez** — dosyada 30+ kullanımı var. Yalnız takma ada dönüşür.

### Adım 3 — Koyu tema override'ı
`#root[data-theme="dark"]{` bloğunun içine ekle:
```css
    --elev-1: 0 1px 2px rgba(0,0,0,.40), 0 2px 8px rgba(0,0,0,.34),
              inset 0 1px 0 rgba(255,255,255,.06);
    --elev-2: 0 2px 4px rgba(0,0,0,.46), 0 8px 20px rgba(0,0,0,.40),
              inset 0 1px 0 rgba(255,255,255,.07);
    --elev-3: 0 4px 8px rgba(0,0,0,.52), 0 16px 36px rgba(0,0,0,.46),
              inset 0 1px 0 rgba(255,255,255,.08);
    --elev-4: 0 8px 16px rgba(0,0,0,.60), 0 28px 60px rgba(0,0,0,.54),
              inset 0 1px 0 rgba(255,255,255,.10);
    --press-dim: 1.12;   /* koyu zeminde karartma değil PARLATMA */
```

### Adım 4 — Reduced-motion (TEK blok, 48 keyframe'e ayrı kural yazma)
Dosyanın FX bölümüne:
```css
@media (prefers-reduced-motion: reduce){
  :root{ --dur-1:1ms; --dur-2:1ms; --dur-3:1ms; --dur-4:1ms; --dur-5:1ms; }
}
```
