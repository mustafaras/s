## 3. ADIMLAR

### Adım 1 — Altın merdivenini `:root`'a ekle
FX2-02 token'larının altına:
```css
    /* ── FX2-04: altın merdiveni — tek hue (38°), 5 basamak ── */
    --gold-1:#F0E2C6;   /* en açık — halo, seçili zemin */
    --gold-2:#D9C29A;   /* açık vurgu (= --accent-soft) */
    --gold-3:#B08D57;   /* ANA aksan (= --accent) */
    --gold-4:#8A6A3B;   /* metin varyantı (= --accent-ink) */
    --gold-5:#5E4826;   /* en koyu — kenarlık, derin gölge */
```

Koyu tema bloğuna:
```css
    --gold-1:#F7ECD8; --gold-2:#F0DBB8; --gold-3:#E3C08A;
    --gold-4:#C9A570; --gold-5:#8A6A3B;
```

### Adım 2 — Mevcut altınları merdivene bağla
Bu dört tanımı **var() ile** merdivene bağla (hex'i sil):

| Bul | Yaz |
|---|---|
| `--aeon:#C99A3A;` | `--aeon:var(--gold-3);` |
| `--aeon2:#E6C15A;` | `--aeon2:var(--gold-2);` |
| `--zikr-counter-gold:#D8B968;` | `--zikr-counter-gold:var(--gold-2);` |

> **Dikkat:** `--aeon` panel.html ile "uyumlu" diye yorumlanmış ama
> `panel.html` **ayrı dosya, ayrı token seti** — burada değişmesi paneli
> etkilemez. Yine de `panel/**` bu kartta açılmaz.

### Adım 3 — Nav/header altın fallback'leri
`--hdr-accent2`, `--nav-active2`, `--nav-item-accent2` fallback değeri
`#A4824C` olarak **satır içinde** geçiyor (örn.
`var(--hdr-accent2,#A4824C)`). Bunların hepsini `var(--gold-3)` yap:

```bash
# önce kaç tane olduğunu gör
grep -o '#A4824C' app/styles.css | wc -l
```
Her `#A4824C` → `var(--gold-3)` (fallback konumunda olduğu için
`var(--hdr-accent2,var(--gold-3))` biçimi geçerlidir).

### Adım 4 — Aurora halkası (M10'u sıfırlar)
**Bul:** `#sey-aurora` kuralındaki `var(--accent-ink,#D96D8B)`
**Yaz:** `var(--accent-ink,#8A6A3B)`
> Üç radial-gradient halkası artık: `--accent` (altın),
> `--room2` (mor, kontrast için korunur), `--accent-ink` (koyu altın).

### Adım 5 — `--accent-soft` merdivene bağla
FX2-03'te hex yazılmıştı; şimdi:
`--accent-soft:#D9C29A;` → `--accent-soft:var(--gold-2);`
(koyu temada `#F0DBB8` → `var(--gold-2)`)
