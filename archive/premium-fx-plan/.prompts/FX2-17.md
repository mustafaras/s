## 3. ADIMLAR

### Adım 1 — CSS
```css
/* FX2-17: liste stagger. JS düğüm gezmez; indeks markup'ta CSS değişkeni. */
.sey-stagger{
  animation: sey-fade-in var(--dur-3) var(--ease-out) backwards;
  animation-delay: calc(var(--i, 0) * 35ms);
}
@media (prefers-reduced-motion: reduce){ .sey-stagger{ animation:none } }
```
> `sey-fade-in` keyframe **zaten var** (FX-1'den). **Yeniden tanımlama.**

### Adım 2 — Liste üreticilerine ekle (hedef ≥ 8)
Kalıp:
```js
'<div class="surface sey-stagger" style="--i:'+Math.min(i,8)+'">'
```

**Hedef yüzeyler:** alışkanlık listesi, kitaplık, izleme, dinleme, rapor
kartları, hatırlatma listesi, zikir presetleri, Saygı kaynak kartları,
motivasyon görev listesi.

Bulmak için:
```bash
grep -n "\.map(function" app.js | head -30
grep -n "for(var i=0;i<.*length;i++)" app.js | head -30
```
