## 3. ADIMLAR

### Adım 1 — Bildirim temelli yaklaşım
Her sayaç hedef değerini markup'ta taşır:
```html
<span class="sey-hero-stat-val" data-countup="7">7</span>
```

### Adım 2 — Tek tarayıcı (`mediaFx.js`, `SeyFx` üzerine)
```js
    sweepCounters: function(){
      if (!document.querySelectorAll) return;
      var nodes = document.querySelectorAll('[data-countup]');
      Array.prototype.forEach.call(nodes, function(el){
        var to = Number(el.getAttribute('data-countup'));
        if (isNaN(to)) return;
        var prevRaw = el.dataset.prev;
        if (prevRaw == null){ el.dataset.prev = String(to); return; }  // ilk boyama: animasyon YOK
        var from = Number(prevRaw);
        if (from === to) return;
        el.dataset.prev = String(to);
        window.SeyFx.countUp({ el: el, from: from, to: to, duration: 500 });
      });
    },
```

### Adım 3 — `render()` sonrası çağır
`paint()` içindeki mevcut `SeyTimeTheme.apply()` guard'ının **yanına**,
aynı desende:
```js
try{ if(window.SeyFx && typeof window.SeyFx.sweepCounters==='function') window.SeyFx.sweepCounters(); }catch(e){}
```

### Adım 4 — `data-countup` bas (hedef ≥ 8)
su, adım, streak, gün indexi, tamamlanan alışkanlık, zikir sayacı,
okunan sayfa, motivasyon gün no, rapor skoru.

### Adım 5 — Halkalar
`ringSeg`'in ürettiği `<circle>`'a sınıf ekle (imza değişmez):
```css
.sey-ring-seg{ transition: stroke-dashoffset var(--dur-4) var(--ease-out); }
@media (prefers-reduced-motion: reduce){ .sey-ring-seg{ transition:none } }
```
