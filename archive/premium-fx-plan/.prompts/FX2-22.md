## NEDEN
Kullanıcının asıl derdi **sıkılma**. Hava + zaman zaten 32 kombinasyon veriyor;
mevsim onu 192'ye çıkarır:

```
4 zaman × 8 hava × 6 mevsim = 192 görsel kombinasyon
```

Kullanıcı aynı zemini iki gün üst üste **neredeyse hiç** görmez. Bu, tek bir
hareketli arka plandan çok daha güçlü bir çözümdür.

Üstüne `--amb-seed` (günün tarihinden türeyen deterministik sayı) gradient
açısını ±8° kaydırır: **aynı hava + aynı saatte bile gün gün ince fark**, ama
gün içinde sabit (titreşim yok).

### Adım 1 — `SeyAmbience.seasonClass` (`timeTheme.js`)

```js
    // Mevsim + özel gün. Mevcut SeyTimeTheme.seasonalClass'a DOKUNMAZ;
    // onun mantığını amb-* ad alanına çevirir.
    seasonClass: function(now){
      var d = now || new Date();
      var m = d.getMonth() + 1, day = d.getDate();
      if (m === 1 && day === 1) return 'amb-season-newyear';
      try{
        if (window.HijriCalendarV1 && window.HijriCalendarV1.todayStr){
          var h = window.HijriCalendarV1.todayStr();
          if (h && /\b9\b/.test(String(h).split(' ')[1] || '')) return 'amb-season-ramazan';
        }
      }catch(e){}
      if (m >= 3  && m <= 5)  return 'amb-season-spring';
      if (m >= 6  && m <= 8)  return 'amb-season-summer';
      if (m >= 9  && m <= 11) return 'amb-season-autumn';
      return 'amb-season-winter';
    },
```

`scene()` içindeki `season:` alanını `this.seasonClass(now)` yap.

### Adım 2 — CSS: mevsim yalnız AKSAN tonunu kaydırır

> **Kritik kural:** mevsim zemini **değiştirmez**. Zemin zamanın, doku
> havanın, aksan mevsimin. Üçü asla aynı özelliği yazmaz — bu yüzden
> birbirini ezmezler.

```css
/* ── FX2-22: mevsim katmanı — yalnız --season-accent ─────────────── */
#root.amb-season-spring { --season-accent:#A3B86C; }
#root.amb-season-summer { --season-accent:#D9B44A; }
#root.amb-season-autumn { --season-accent:#C08552; }
#root.amb-season-winter { --season-accent:#8FA6B8; }
#root.amb-season-ramazan{ --season-accent:#6E9E8A; }
#root.amb-season-newyear{ --season-accent:#C9A227; }

#root[data-theme="dark"].amb-season-spring { --season-accent:#BCD08A; }
#root[data-theme="dark"].amb-season-summer { --season-accent:#EBCB6A; }
#root[data-theme="dark"].amb-season-autumn { --season-accent:#D9A272; }

/* Mevsim aksanı yalnız iki kalıcı yüzeyin kenar ışığında görünür —
   metin veya zemin rengine ASLA karışmaz (kontrast riski sıfır). */
#root[class*="amb-season-"] .sey-appheader{
  box-shadow: var(--elev-3),

  box-shadow: var(--elev-3),
              0 10px 22px color-mix(in srgb,var(--season-accent) 18%,transparent);
}
```

### Adım 3 — Günlük varyasyon (`--amb-seed`)
Zaman gradientlerini seed ile döndür:
```css
#root[class*="amb-time-"]{
  --amb-angle: calc(170deg + (var(--amb-seed, .5) - .5) * 16deg);
}
#root.amb-time-dawn { --page: linear-gradient(var(--amb-angle),#FFF6EC 0%,#FBEBD8 46%,#F4EFF2 100%); }
```
(Dört zaman kuralında `170deg` → `var(--amb-angle)`.)

> `--amb-seed` `apply()` tarafından zaten yazılıyor (FX2-20 Adım 2).
> Gün içinde **sabit**, gün gün değişir. ±8° kayma göze "aynı ekran değil"
> dedirtir ama fark ettirmez.
