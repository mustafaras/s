## 3. ADIMLAR

### Adım 1 — Kademe ataması
| Yüzey | Token |
|---|---|
| `.surface`, `.card`, `.bento` | `--elev-2` |
| `.sey-appheader`, `.sey-bottomnav-surface` | `--elev-3` |
| Overlay kartları (`.sey-ov-card`, zikr/qibla/faith kabukları) | `--elev-4` |
| Küçük alanlar (`.field`) | `--elev-1` |

Mevcut `box-shadow:0 …` bildirimlerini `var(--elev-N)` ile değiştir.

### Adım 2 — Zaman/mevsim vurguları KORUNUR, birleştirilir
```css
#root[class*="amb-time-"] .sey-appheader{
  box-shadow: var(--elev-3), 0 8px 18px var(--surface-accent);
}
```
> Vurgu **silinmez**, elevation'ın **üstüne** eklenir.

### Adım 3 — Hover derinliği
```css
@media (hover:hover){
  .surface{ transition: transform var(--dur-2) var(--ease-out),
                        box-shadow var(--dur-2) var(--ease-out); }
  .surface:hover{ transform:translateY(-2px); box-shadow:var(--elev-3); }
}
@media (prefers-reduced-motion: reduce){
  .surface,.surface:hover{ transition:none!important; transform:none!important; }
}
```
> `.surface:active` **eklenmez** — FX2-07'de bilinçli kaldırıldı.

### Adım 4 — `will-change` disiplini
Yalnız `@media (hover:hover)` içinde ve yalnız hover'lı yüzeylerde.
Toplam `will-change` sayısı **artmamalı**.
