# IIP-08 görsel kabul kanıtı

Artifact: [`render-matrix.html`](render-matrix.html)

Bu dosya, paket A'nın mevcut IIP-05/IIP-06/IIP-07 render kanıtlarını aynı risk-temelli kabul matrisi altında toplar. Matris light/dark, 320/390/768 px, %200 metin, reduced-motion, loading/empty/error/ready/return ve 430/1280 px ortak yerleşim sınırlarını kapsar.

`render-matrix.html` ağsız, kişisel verisiz sentetik bir HTML render artifact'idir. Browser screenshot, fiziksel cihaz, VoiceOver veya kullanıcı kabulü değildir. Bu nedenle yayın tamamlanmış olsa bile `deviceAcceptance` `not_verified` olarak kalır.
