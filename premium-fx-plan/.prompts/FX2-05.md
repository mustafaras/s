### Test grupları (12 grup)

1. **Pembe yok:** `C77D93|B55471|FFB1CF|FCEDEE|F1EBFF|D96D8B` → 0 eşleşme.
2. **Kandil korundu:** `9C4A5A` ve `D68A94` → hâlâ var.
3. **Hub renkleri korundu:** `--read:#6E55BF`, `--watch:#B5732E`,
   `--listen:#0E8F9C`, `--sun:#F5A623`, `--warn:#E5484D` → değişmemiş.
4. **Altın merdiveni:** `--gold-1..5` her iki temada tanımlı, 5'i de geçerli hex.
5. **Merdiven monotonluğu:** `--gold-1` en açık, `--gold-5` en koyu
   (relative luminance azalan sırada).
6. **Hue tutarlılığı:** `--gold-1..5` hue'ları birbirinden **≤ 12°** farklı
   (tek aile kanıtı).
7. **Kontrast — açık tema (4 çift, hepsi ≥ 4,5:1):**
   `--accent-ink` / `#FDFBF7`, `--accent-ink` / `#F7F1E8`,
   `--text` / `#FDFBF7`, `--text` / `#F2EFF4`
8. **Kontrast — koyu tema (4 çift, hepsi ≥ 4,5:1):**

9. **Dolgu eşiği:** `--accent` (`--gold-3`) beyaz üstünde **≥ 3:1**

10. **Token bütünlüğü:** `--accent`, `--accent-ink`, `--accent-soft`,

11. **Ham hex sızıntısı yok:** `--aeon`, `--aeon2`, `--zikr-counter-gold`

12. **`--page` gradienti:** 3 durak, hiçbiri pembe hue aralığında
    (300°–360° veya 0°–20°'de doygunluk > %15 olan durak yok).

**Kontrast fonksiyonu** (fixture içinde, kütüphanesiz):
```js
function srgb(v){ v/=255; return v<=0.03928 ? v/12.92 : Math.pow((v+0.055)/1.055, 2.4); }
function lum(hex){
  const h = hex.replace('#','');
  return 0.2126*srgb(parseInt(h.slice(0,2),16))
       + 0.7152*srgb(parseInt(h.slice(2,4),16))
       + 0.0722*srgb(parseInt(h.slice(4,6),16));
}
function ratio(a,b){ const A=lum(a),B=lum(b); return (Math.max(A,B)+0.05)/(Math.min(A,B)+0.05); }
```
