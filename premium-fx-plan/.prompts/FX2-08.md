## 3. ADIMLAR

### Adım 1 — `SeyFx.ripple` imzasını genişlet (geriye uyumlu)

**Bul:** `ripple: function(event, color){`
**Yaz:** `ripple: function(event, color, targetEl){`

Gövdenin başındaki eleman seçimini değiştir:
```js
      if (!isPremiumFxEnabled()) return;
      var el = targetEl || (event && event.currentTarget);
      if (!el || !el.getBoundingClientRect) return;
      var rect = el.getBoundingClientRect();
      // Ölçülebilir kutusu olmayan elemanı atla (ikon-only span vb.)
      if (rect.width < 8 || rect.height < 8) return;
      // Konteyner sınıfı runtime'da takılır — 361 butonun markup'ı değişmez
      if (!el.classList.contains('sey-ripple')) el.classList.add('sey-ripple');
      // Satır içi stille yazılmış butonlarda position:static olabilir; dalga kaçmasın
      if (getComputedStyle(el).position === 'static') el.style.position = 'relative';
```

> `targetEl` verilmezse mevcut `event.currentTarget` yolu **aynen** çalışır.

### Adım 2 — Temizliği çift emniyete al
Dalga kaldırma bloğunu şununla değiştir:
```js
      var gone = false;
      function drop(){ if (gone) return; gone = true; try{ wave.remove(); }catch(e){} }
      wave.addEventListener('animationend', drop, { once: true });
      setTimeout(drop, 600);
```

### Adım 3 — Yıkıcı eylemde renk ayrımı
`color` verilmemişse ve `el.dataset.fx === 'destructive'` ise dalga rengi
`--drop` tonuna kayar:
```js
      if (!color && el.dataset && el.dataset.fx === 'destructive'){
        color = 'color-mix(in srgb, var(--drop) 55%, transparent)';
      }
```

### Adım 4 — CSS: konteyner güvenliği
`.sey-ripple` kuralına ekle (mevcut `position:relative;overflow:hidden` kalır):
```css
  isolation: isolate;   /* dalga, kartın kendi z-index'ini bozmasın */
```
