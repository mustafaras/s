## NEDEN
iOS Safari `AudioContext`'i kullanıcı jesti olmadan başlatmaz. Şu anki kod
`ctx.resume()`'u **her sesin içinde** çağırıyor — jest bağlamı dışına
düşebilir ve ilk tıklamalarda ses gelmez. Ayrıca uygulama arka plandayken
bağlam açık kalıyor (batarya).

Bu kart `M9`'un **ikinci** kanalını (ses) iOS'ta güvenceye alır; birinci kanal
görsel basma durumudur (FX2-07). **Haptik iOS'ta yoktur** — bu kabul edilir ve
yerine bu iki kanal konur.

## 3. ADIMLAR

### Adım 1 — Tek seferlik kilit açma
`SeyTouch.install()` içine, **ayrı `{once:true}` dinleyici**:
```js
      root.addEventListener('pointerdown', function unlock(){
        try{
          var c = bootCtx(); if (!c) return;
          if (c.state === 'suspended') c.resume();
          var b = c.createBuffer(1, 1, c.sampleRate);
          var s = c.createBufferSource(); s.buffer = b;
          s.connect(c.destination); s.start(0);
          window.SeyAudio._unlocked = true;
        }catch(e){}
      }, { once: true, passive: true });
```
> Jest bağlamı **içinde** çalıştığı için iOS kilidini kalıcı açar.

### Adım 2 — Görünürlük yönetimi
```js
  document.addEventListener('visibilitychange', function(){
    try{
      var c = CTX; if (!c) return;
      if (document.hidden){
        if (window.SeyAudio.ambient && window.SeyAudio.ambient.isPlaying()) window.SeyAudio.ambient.stop();
        c.suspend();
      } else if (window.SeyAudio._unlocked){
        c.resume();
      }
    }catch(e){}
  });
```

### Adım 3 — `resume()`'u ses gövdelerinden çıkar
`playTone`/`playArpeggio`/`playBell`/`playVoice` içindeki
`if (ctx.state === 'suspended') ctx.resume();` satırları **silinir**.
Yerine: `if (ctx.state !== 'running') return;` — sessizce atla, hata basma.

### Adım 4 — `SeyAudio.isAudible()` ekle (yeni, I2 uyumlu)
```js
    isAudible: function(){
      try{ var c = bootCtx(); return !!(c && c.state === 'running' && allowed()); }
      catch(e){ return false; }
    },
```
