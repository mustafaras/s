# FX2-P-01 — Kapsam Denetçisi ve Taban Çizgisi

**Dalga:** 0 · **Tip:** araç (uygulama davranışı değişmez) · **Hedef:** ölçüm altyapısı

## Neden
FX-1'de 9/9 fixture yeşilken `SeyAudio.tap` **0 kez** çağrılıyordu. Bu kart,
"bağlandı mı?" sorusunu makineye sorduran aracı kurar. Bu araç olmadan
FX2-P-11 ve sonrası **başlatılamaz**.

## Ön okuma
- `premium-fx-plan/TESHIS.md` (tamamı)
- `premium-fx-plan/KAPSAM-OLCUMU.md` §2–§4

## Değiştirilecek
- `tools/fx-coverage.mjs` **(yeni)**
- `premium-fx-plan/.anti-amnesia/coverage.json` **(yeni)**

**Dokunma:** `app.js`, `app/**`, `index.html`, `tests/**`.

## Adımlar

1. `tools/` dizini yoksa oluştur.

2. `tools/fx-coverage.mjs` yaz. Zorunlu özellikler:
   - **Salt-okur.** Hiçbir dosyaya yazmaz (`--save` hariç, o da yalnız
     `coverage.json`). Ağ yok, `localStorage` yok, `app.js` VM'de
     **çalıştırılmaz** — yalnız statik metin analizi.
   - Okuduğu dosyalar: `app.js`, `app/styles.css`, `app/core/mediaFx.js`,
     `app/core/timeTheme.js`, `app/core/state.js`, `index.html`.
   - `KAPSAM-OLCUMU.md` §2'deki M1–M9 metriklerini hesaplar:

     | Metrik | Statik sayım kuralı |
     |---|---|
     | M1 | `<button` sayısı + `onclick=` taşıyan `<div`/`<span`/`<a` sayısı |
     | M2 | `SeyTouch` seçici sabiti bulunursa: seçicinin kapsadığı eleman türleri × M1'deki karşılıkları; katman yoksa 0 |
     | M3 | Ayrık ses tetikleme yolu: açık `SeyAudio.<ad>(` çağrıları + delege katman varsa M2 |
     | M4 | Ripple delege katmana bağlıysa M2; değilse `onclick="App.x(event` sayısı |
     | M5 | `SeyFx.countUp(` çağrısı + `data-countup` geçen satır sayısı |
     | M6 | `sey-sheet-out`/çıkış sınıfı geçen `App.closeX` gövdesi sayısı |
     | M7 | Token (`var(--dur-`/`var(--ease-`) kullanan `transition:`+`animation:` bildirimi / toplam |
     | M8 | `state.js` `migrate()` içinde `=false` atanan premium ayar sayısı |
     | M9 | iOS'ta çalışan kanal: görsel basma (`.sey-press` CSS+JS) 1 + ses kilidi (`resume` + sessiz buffer) 1 + `vibrate` 0 |

   - Çıktı: hizalı tablo (metrik, taban, şimdi, delta, eşik, ✅/❌).
   - Bayraklar: `--save` (taban yaz), `--gate` (eşik altında `exit 1`),
     `--json` (ham JSON).
   - Eşikler `KAPSAM-OLCUMU.md` §4 tablosundan **kod içinde sabit** tanımlanır.

3. Çalıştır ve tabanı yaz:
   ```bash
   node tools/fx-coverage.mjs
   node tools/fx-coverage.mjs --save
   ```

4. Üretilen `coverage.json`'u `KAPSAM-OLCUMU.md` §3'teki beklenen değerlerle
   karşılaştır. **Sapma varsa belgeyi değil, aracı düzelt** — belge gerçek
   sayımdan üretildi. Gerçekten farklıysa §3'ü ölçülen değerle güncelle ve
   farkı `LEDGER.md`'ye yaz.

## Doğrulama
```bash
node --check tools/fx-coverage.mjs
node tools/fx-coverage.mjs --json | python3 -m json.tool > /dev/null && echo "JSON OK"
node tools/fx-coverage.mjs --gate; echo "gate exit=$?"     # taban=eşik değil → exit 1 beklenir
git status --short   # yalnız tools/ ve .anti-amnesia/coverage.json
```
