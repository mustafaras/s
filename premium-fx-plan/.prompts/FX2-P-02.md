## Adımlar

1. `app/styles.css` içindeki mevcut `:root` bloğunu bul
   (`grep -n '\-\-ease-premium' app/styles.css`). Token'ları **oraya**, mevcut
   `--ease-premium` satırının hemen altına ekle — yeni bir `:root` bloğu açma.

2. `HAREKET-SISTEMI.md` §1'deki tam listeyi ekle: `--dur-1..5`,
   `--ease-out/in/spring/glide`, `--elev-0..4`, `--press-scale`, `--press-dim`.

3. **Geriye uyum (zorunlu):** `--ease-premium` **silinmez**. Yeni tanımı:
   ```css
   --ease-premium: var(--ease-out);
   ```
   Böylece 30+ mevcut kullanım aynen çalışır.
   Doğrula: `grep -c 'ease-premium' app/styles.css` **azalmamalı**.

4. Koyu tema: `#root[data-theme="dark"]` bloğunda `--elev-1..4`'ü yeniden
   tanımla — gölge opaklığı yüksek, iç ışık düşük.

5. Reduced-motion: **tek** blok ekle, 48 keyframe'e ayrı kural yazma:
   ```css
   @media (prefers-reduced-motion: reduce){
     :root{ --dur-1:1ms; --dur-2:1ms; --dur-3:1ms; --dur-4:1ms; --dur-5:1ms; }
   }
   ```

6. **Bu kartta hiçbir mevcut kural yeniden yazılmaz.** Token'lar tanımlanır,
   kullanımı FX2-P-12/31/41'e bırakılır. Amaç: sıfır görsel regresyon.

7. `index.html`: `app/styles.css?v=` bump.
