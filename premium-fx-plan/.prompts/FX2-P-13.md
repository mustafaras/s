# FX2-P-13 — Ripple'ı Delege Katmana Bağla

**Dalga:** 1 · **Tip:** entegrasyon · **Hedef:** M4 0 → **≥ %90 (≥325)**

## Neden
`SeyFx.ripple` var, CSS'i var, **tek çağrısı tetiklenemiyor**: `event`
gerektiriyor ama `grep -o 'onclick="App\.[A-Za-z]*(event' app.js` → **0**.
Üstelik hedef eleman `.sey-ripple` konteyner sınıfını taşımadığı için dalga
kırpılmadan taşardı. FX2-P-11 artık gerçek `PointerEvent`'i ve gerçek elemanı
elinde tutuyor — bağlama zamanı.

**Dokunma:** `app.js`.

## Adımlar

1. **`SeyFx.ripple` imzasını genişlet — geriye uyumlu:**
   ```js
   ripple: function(event, color, targetEl){ ... }
   ```
   `targetEl` verilmişse onu kullan; verilmemişse mevcut
   `event.currentTarget` yolu **aynen** korunur (I2 — mevcut çağrı kırılmaz).

2. **Konteyner sınıfını runtime'da tak.** Dalga eklemeden önce:
   ```js
   if(!el.classList.contains('sey-ripple')) el.classList.add('sey-ripple');
   ```
   Böylece 361 butonun markup'ına dokunmadan hepsi ripple konteyneri olur.
   **Uyarı:** `overflow:hidden` bazı elemanlarda içeriği kırpabilir —
   `.sey-ripple` kuralına `overflow:clip` düşmeden `overflow:hidden` kalsın,
   ama sınıf yalnız **ölçülebilir kutusu olan** elemanlara takılsın:
   ```js
   var r = el.getBoundingClientRect();
   if(r.width < 8 || r.height < 8) return;   // ikon-only span vb. atla
   ```

3. **Konumlandırma:** `getComputedStyle(el).position === 'static'` ise
   `el.style.position = 'relative'` — dalga elemanın dışına kaçmasın.
   Bu tek satır, satır içi stille yazılmış 277 buton için kritik.

4. **Temizlik:** dalga `animationend` **veya** 600 ms timeout'ta kaldırılır
   (hangisi önce gelirse). `render()` DOM'u yenilerse dalga zaten yok olur —
   sızıntı olmaz.

5. **Renk:** `color` verilmezse `currentColor` (mevcut CSS zaten öyle).
   `data-fx="destructive"` ise `--drop` tonuna kaydır (FX2-P-14 ile eşleşir).

6. FX2-P-11'deki `SeyFx.ripple(e, null, el)` çağrısını etkinleştir.

7. `index.html`: `mediaFx.js?v=` + `styles.css?v=` bump.
