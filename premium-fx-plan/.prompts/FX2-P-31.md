# FX2-P-31 — Sekme Geçiş Motoru

**Dalga:** 3 · **Tip:** entegrasyon · **Hedef:** 7 sekmenin 7'sinde gerçek geçiş

## Neden
`render()` `app.innerHTML = html` ile ekranı yıkıyor; çıkış animasyonu
imkânsız, geçiş "flaş" gibi. Şu an `App.go` yalnız `SeyFx.enter` çağırıyor
(giriş var, çıkış yok). Premium his çıkış + giriş çiftinden doğar.

## Ön okuma
- `premium-fx-plan/HAREKET-SISTEMI.md` §3
- `app.js` `App.go` (satır ~5863) ve `render()`/`paint()` (satır ~8951)

## Değiştirilecek
- `app.js` (`App.go` gövdesi), `app/styles.css`, `index.html` (bump)

**Dokunma:** `render()`, `paint()`, scroll/odak restorasyonu (I7).

## Adımlar

1. **CSS** (`app/styles.css` FX bölümü):
   ```css
   #app.sey-leaving { opacity:0; transform:translateY(6px);
     transition:opacity var(--dur-2) var(--ease-in), transform var(--dur-2) var(--ease-in); }
   #app.sey-entering { opacity:0; transform:translateY(-6px); }
   #app { transition:opacity var(--dur-3) var(--ease-out), transform var(--dur-3) var(--ease-out); }
   @media (prefers-reduced-motion: reduce){
     #app, #app.sey-leaving, #app.sey-entering{ transition:none!important; opacity:1!important; transform:none!important; }
   }
   ```

2. **`App.go` yeniden düzenlenir** — `render()` çağrısı **aynen korunur**,
   yalnız zamanlaması sarmalanır:
   ```
   tabChanged değilse → mevcut davranış, hiç değişiklik
   premium kapalı VEYA reduced-motion → mevcut davranış (senkron render)
   aksi hâlde:
     #app.classList.add('sey-leaving')
     bekle: transitionend VEYA 200ms timeout (hangisi önce)
       → mevcut gövde aynen: ui.tab=id; render(); scrollTop=0; tryLocNudge('tab')
       → 'sey-leaving' kaldır, 'sey-entering' ekle
       → requestAnimationFrame ×2 → 'sey-entering' kaldır
   ```

3. **Timeout zorunlu.** `transitionend` gelmeyebilir (arka plan sekmesi, düşük
   güç modu, `display:none`). Timeout olmadan uygulama **kilitlenir**.
   `Promise.race` yerine basit bayrak + `clearTimeout` kullan (ES5 uyumu).

4. **Yeniden giriş koruması:** geçiş sürerken ikinci `App.go` gelirse
   bekleyen timeout iptal edilir ve **doğrudan** yeni sekmeye gidilir
   (kullanıcı hızlı sekme değiştirebilmeli).

5. `SeyAudio.nav()` çağrısı FX2-P-14 `data-fx="nav"` üzerinden zaten geliyor —
   `App.go` içine **ayrıca ses ekleme** (çift ses olur).

6. Mevcut `SeyFx.enter` çağrısı korunur; `sey-entering` ile çakışmaması için
   `enter` **`render()` sonrası** çalışmaya devam eder.
