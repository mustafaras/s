## Adımlar

1. **CSS:**
   ```css
   .sey-sheet-in  { animation: sey-sheet-in  var(--dur-4) var(--ease-spring); }
   .sey-sheet-out { animation: sey-sheet-out var(--dur-3) var(--ease-in) forwards; }
   @keyframes sey-sheet-in  { from{ transform:translateY(100%); opacity:.4 } to{ transform:none; opacity:1 } }
   @keyframes sey-sheet-out { to  { transform:translateY(100%); opacity:0 } }
   .sey-backdrop-out { animation: sey-backdrop-out var(--dur-3) var(--ease-in) forwards; }
   @keyframes sey-backdrop-out { to { opacity:0; backdrop-filter:blur(0) } }
   @media (prefers-reduced-motion: reduce){
     .sey-sheet-in,.sey-sheet-out,.sey-backdrop-out{ animation:none!important }
   }
   ```

2. **Ortak yardımcı** (`mediaFx.js`, `SeyFx` üzerine):
   ```js
   SeyFx.sheetClose(cardId, backdropId, done)
   ```
   - premium kapalı / reduced-motion → `done()` **hemen** çağrılır
   - aksi hâlde sınıflar takılır, `animationend` **veya 260 ms** sonra `done()`
   - `done` **en fazla bir kez** çalışır (bayrak)

3. **Her `App.closeX` sarmalanır**, gövdesi **aynen** `done` içine taşınır:
   ```js
   App.closeReading = function(){
     var body = function(){ /* MEVCUT GÖVDE — TEK KARAKTER DEĞİŞMEZ */ };
     if(window.SeyFx && SeyFx.sheetClose) SeyFx.sheetClose('sey-ov-card','sey-ov-back',body);
     else body();
   };
   ```
   Kapsam: `closeReading, closeWatching, closeListening` + zikr, qibla, faith,
   quranJourney, saygiPerson, soulArchive, soulActivity, learning,
   reminderCenter kapatıcıları → **≥ 10 adet**.

4. **Açılış:** overlay kart markup'ına `class="… sey-sheet-in"` eklenir
   (render her seferinde yeniden ürettiği için animasyon doğal olarak
   yalnız açılışta oynar).

5. **Odak sözleşmesi korunur:** `focusModalDialog` çağrısı `done()` içinde,
   `render()` sonrasında kalır — sırası değişmez.

6. **Escape yolu:** `App.onModalKeydown` Escape dalı da aynı sarmalayıcıdan
   geçer (ayrı yol açma).
