# FX2-P-33 — Stagger Sistemi (`--i`)

**Dalga:** 3 · **Tip:** CSS + markup · **Hedef:** ≥ 8 liste yüzeyi

## Neden
`SeyFx.enter` tek yerde (sekme değişimi) ve JS ile düğüm geziyor
(`querySelectorAll` + `animationDelay` yazma). Kartların sırayla belirmesi
premium algının ucuz ama en etkili parçalarından biridir — CSS ile bedava
yapılabilir.

## Ön okuma
- `premium-fx-plan/HAREKET-SISTEMI.md` §5
- `app.js` — liste üreten döngüler (`.map(`, `for` ile HTML biriktirme)

## Değiştirilecek
- `app.js` (yalnız `style="--i:N"` eklemek), `app/styles.css`, `index.html`

## Adımlar

1. **CSS:**
   ```css
   .sey-stagger{ animation: sey-fade-in var(--dur-3) var(--ease-out) backwards;
                 animation-delay: calc(var(--i, 0) * 35ms); }
   @media (prefers-reduced-motion: reduce){ .sey-stagger{ animation:none } }
   ```
   `sey-fade-in` keyframe zaten var (FX-1'den) — yeniden tanımlama.

2. **Liste üreticilerine ekle** — hedef ≥ 8 yüzey:
   alışkanlık listesi, kitaplık, izleme, dinleme, rapor kartları,
   hatırlatma listesi, zikir presetleri, Saygı kaynak kartları,
   motivasyon görev listesi.

   Kalıp:
   ```js
   '<div class="surface sey-stagger" style="--i:'+Math.min(i,8)+'">'
   ```

3. **`Math.min(i,8)` zorunlu** — 114 sûrelik listede son kart 4 saniye
   beklememeli.

4. **ÆON sohbetinde dikkat:** mesaj listesi her render'da yeniden kuruluyor;
   stagger her 30 sn'lik yoklamada tekrar oynarsa **rahatsız edici** olur.
   Orada `.sey-stagger` **kullanma**; kapsamı diğer 8 yüzeyden doldur.

5. `SeyFx.enter`'ın `App.go` çağrısı korunur (I2), ama artık ana yol CSS.
