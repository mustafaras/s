# FX2-P-41 — Elevation Skalası Uygulaması

**Dalga:** 4 · **Tip:** CSS · **Hedef:** M7 → ≥ 0,80

## Neden
FX2-P-02 `--elev-1..4` token'larını tanımladı ama **kullanmadı**. Kartlar hâlâ
tek katmanlı, düz gölgeyle çiziliyor. Gerçek malzeme hissi katmanlı gölge
(yakın + uzak) + iç ışık (`inset`) + kenar tonundan doğar.

## Ön okuma
- `premium-fx-plan/HAREKET-SISTEMI.md` §1, §7
- `app/styles.css` — `.surface`, `.glass`, `.sey-appheader`, `.sey-bottomnav`

## Değiştirilecek
- `app/styles.css`, `index.html` (bump)

**Dokunma:** `app.js` (markup değişmez — sınıflar zaten yerinde).

## Adımlar

1. **Kademe ataması:**
   | Yüzey | Token |
   |---|---|
   | `.surface`, `.card`, `.bento` | `--elev-2` |
   | `.sey-appheader`, `.sey-bottomnav-surface` | `--elev-3` |
   | Overlay kartları (`.sey-ov-card`, zikr/qibla/faith kabukları) | `--elev-4` |
   | Satır içi küçük alanlar (`.field`) | `--elev-1` |

2. **Mevcut `box-shadow` bildirimleri token'a çevrilir.**
   `#root.theme-time-*` ve `#root.theme-season-*` kurallarındaki gölgeler
   **korunur** — onlar renk vurgusu, elevation değil; `--elev-*` ile
   birleştirilir:
   ```css
   #root.theme-time-dawn .sey-appheader{
     box-shadow: var(--elev-3), 0 8px 18px var(--surface-accent);
   }
   ```

3. **Hover derinliği** (`@media (hover:hover)`): `.surface:hover` → `--elev-3`
   + `translateY(-2px)`, `--dur-2/--ease-out`.

4. **Koyu tema:** `--elev-*` FX2-P-02'de zaten yeniden tanımlı; burada ek
   kural yazılmaz.

5. **Kontrast koruması:** gölge değişimi metin/zemin kontrastını etkilemez;
   yine de mevcut kontrast fixture'ı çalıştırılır.

6. **`will-change` disiplini:** yalnız hover'lı yüzeylerde ve yalnız
   `@media (hover:hover)` içinde.
