# FX2-P-42 — Zaman Teması v2 (gerçek zemin kayması)

**Dalga:** 4 · **Tip:** entegrasyon · **Hedef:** kontrast ≥ 4,5:1, tüm zemin

## Neden
`#root.theme-time-*` şu an **yalnız iki elemanın `box-shadow` rengini**
değiştiriyor (`.sey-appheader`, `.sey-bottomnav-surface`). Sayfa zemini, kart
rengi, aksan rengi hiç değişmiyor. Plan "sabah/öğlen/akşam/gece gradient
geçişi" diyordu; uygulanan şey bir gölge tonu (TEŞHİS §7).

## Ön okuma
- `premium-fx-plan/HAREKET-SISTEMI.md` §7
- `app/core/timeTheme.js` (65 satır — tamamı)
- `app/styles.css` satır ~400–446 (`theme-time-*` / `theme-season-*` blokları)

## Değiştirilecek
- `app/styles.css`, `app/core/timeTheme.js` (yalnız gerekiyorsa), `index.html`

**Dokunma:** `classForHour` saat aralıkları (fixture'lar bunlara bağlı),
`apply()`/`applySeasonal()` imzaları.

## Adımlar

1. **Her saat dilimi için zemin token'ları** (açık + koyu, 8 blok):
   ```css
   #root.theme-time-dawn  { --page: … ; --bg: … ; --card: … ; }
   #root.theme-time-day   { … }
   #root.theme-time-dusk  { … }
   #root.theme-time-night { … }
   ```
   Ton yönü: dawn = sıcak şeftali, day = nötr-açık, dusk = amber-gül,
   night = soğuk lacivert. **Kayma çok ince olsun** — mevcut sakin kimlik
   bozulmamalı (PLAN §1 vizyonu).

2. **Crossfade:**
   ```css
   #root{ transition: background-color var(--dur-5) var(--ease-glide); }
   ```
   `--dur-5` = 800 ms; saat değişimi 30 sn'lik poll'da yakalandığı için
   kullanıcı ani sıçrama görmez.

3. **Kontrast kapısı — bu kartın en önemli maddesi.** Her 4 dilim × 2 tema =
   8 kombinasyon için `--text`/`--page` oranı **≥ 4,5:1** olmalı.
   Mevcut kontrast fixture'ına (`tests/app/` içindeki kontrast testi) 8 yeni
   assertion eklenir. **Oran tutmuyorsa ton azaltılır, fixture gevşetilmez.**

4. **Mevsimsel katman aynı kalır** — yalnız `--season-accent`; zemine
   karışmaz (iki katman üst üste binerse renk kontrolü kaybolur).

5. **`timeTheme.js` değişikliği muhtemelen gerekmez** — `apply()` zaten doğru
   sınıfı takıyor. Yalnız CSS tarafı eksikti. Gerekiyorsa **yalnız** ek
   yorum/guard eklenir; saat aralıklarına dokunulmaz.

6. `index.html`: `styles.css?v=` (+ `timeTheme.js?v=` değiştiyse) bump.
