## 1. Seçilen teknik yaklaşım ve gerekçesi

Header hava efekti, eski CSS `repeating-linear-gradient` / döşenmiş `radial-gradient` dokularının yerini alan **tek canvas parçacık motorudur** (`app/core/skyFx.js`, ~350 satır, IIFE, `window.SeySkyFx`).

| Karar | Gerekçe |
|---|---|
| Canvas 2D (WebGPU değil) | Mobil Safari/PWA hedefi; 414×168 header için 2D yeterli; GPU bağımlılığı gereksiz. |
| `requestAnimationFrame` yalnız (`setInterval` YASAK) | SKY-00 §3 değişmezi; sekme gizliyken `visibilitychange` ile duraklatma. |
| Derinlik tabanlı parçacıklar (d∈[0.35,1]) | Eski CSS'in hatası tek hız/tek açıydı → "diyagonal şerit". Hız, boy, opaklık derinlikten türer. |
| Deterministik yıldız dağılımı (`sc.seed`) | Gün içinde sabit, gün gün farklı — CSS ile imkânsızdı. |
| Yönlü şimşek (radyal gradient) | Eski `filter: brightness()` tüm katmanı parlatıyordu; artık ışık kaynağı konumlu, `CYCLE=31 sn`, ikincil parlama gecikmeli. |
| DPR ölçekli çizim (`scale(dpr,dpr)`) | Retina keskinliği, fillRect boyutu CSS px'te kalır. |
| `mount/unmount` render-bağımlı | `render()` header'ı her seferinde yıktığı için her boyamada `mountSkyCanvas()` yeniden çağrılır; parçacık durumu modülde (`S.drops/flakes`) yaşadığı için süreklilik korunur. |
| Eski CSS dokuları tamamen silindi (SKY-11) | Canvas üstüne binen çift katman kirliliği; gökyüzü gradienti + `sky-time-*` paletleri kaldı. |

**Entegrasyon (SKY-10):** `skySceneNow()` → `SeyAmbience.scene()` + `data.weather.spots[0]` (yeni ağ çağrısı YOK); `mountSkyCanvas()` → `syncHeaderScene()` sonu ve render kuyruğu (`sweepCounters` altı).
